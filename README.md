# word-practice-app
Help stroke survivors use neuroplasticiity to strengthen visual and tonotopic comprehension to combat aphasia. 
Status: VERY early prototype
Disclaimer: This is not a medical grade tool nor a replacement for speech-language therapy;, it is solely intended as a tool to supplement learning. 
Roadmap: Add a first set (done) --> Add sets and organize by topic --> Add photos to the sets --> Melodic Intonation Feature --> Caregiver settings/Progress tracker
